# 麻雀ルール仕様

更新日: 2026-10-31(Issue #29 のヒアリングで変更可の項目とプリセットを確定)

本アプリが計算の前提とする三人麻雀のルール。オーナーの提示(2026-10-20)を正本とし、確度を【確定】【未確定】のタグで区別する。扱い方は[業務標準07](rules/07-mahjong-rule-protocol.md)による。

- 【確定】雀魂・麻雀一番街に準拠する。この文書に書かれた内容は、準拠先より優先する
- 【確定】雀魂と麻雀一番街のどちらのルールにも対応する。各項目は利用者が好みで設定できるようにする
- 【確定】プリセットは「段位戦ルール」の1つとする。雀魂・麻雀一番街の三麻段位戦は、変更可の全項目で所定値が同じであるため(Issue #29。出典はオーナーが両アプリの段位戦・大会戦・友人戦のルールを調べてまとめた一覧表、2026-10-31)。段位戦ルールの値は、この文書の所定値(**太字**)とする
- 【確定】雀魂と麻雀一番街の違いのうち、ツモ損なしのときの方式(§3.1)と赤ドラ4枚の可否(§1)は、計算コアでは区別しない。どちらの方式・枚数も選べるようにする(Issue #29)

「設定」欄が「変更可」の項目は、ルール設定で切り替えられるようにする。所定値は**太字**で示す。

## 1. 牌とドラ

| 項目 | 内容 | 設定 |
| --- | --- | --- |

| 赤ドラ | 【確定】`5p`・`5s` のみ。赤なし／**2枚**(5p・5s 各1枚)／4枚(5p・5s 各2枚)。全赤は採用しない。4枚は麻雀一番街のみの設定だが、本アプリでは制限しない(Issue #29) | 変更可 |
| ドラ表示牌 | 【確定】萬子は表示牌 `1m` でドラ `9m`、表示牌 `9m` でドラ `1m`。筒子・索子・字牌は通常どおり | — |
| 槓ドラ・槓裏 | 【確定】あり。めくるタイミングは点数に関係しないため管理しない | — |
| 裏ドラ | 【確定】あり(立直時) | — |

## 3. 点数と支払い

### 3.1 ツモ損

| 方式 | 内容 | 設定 |
| --- | --- | --- |
| **ツモ損あり** | 【確定】通常どおり計算し、北家の負担分は誰も払わない | 変更可 |
| 北家分折半 | 【確定】北家の負担額を、ツモられた2人で折半して上乗せする | 変更可 |
| ロン打点折半 | 【確定】ロンの打点を、親子に関わらず2人で折半して支払う | 変更可 |

満貫ツモの例(【確定】):

| 方式 | 親のツモ | 子のツモ |
| --- | --- | --- |
| ツモ損あり | 4000オール → 8000点 | 2000・4000 → 6000点 |
| 北家分折半 | 6000オール → 12000点 | 3000・5000 → 8000点 |
| ロン打点折半 | 6000オール → 12000点 | 4000オール → 8000点 |

- 【確定】端数処理(Issue #13。雀魂・麻雀一番街の実機画面で照合):
  - ツモ損あり: 四麻のツモ支払額(100点単位に切り上げ済み)のうち、北家の負担分を誰も払わない
  - 北家分折半(雀魂方式): 四麻のツモ支払額(100点単位に切り上げ済み)に、北家の支払額の1/2を足し、100点単位に切り上げる(例: 子30符2飜ツモは 800・1300)
  - ロン打点折半(一番街方式): 基本点Pから直接計算し、子のツモは ceil100(2P) オール、親のツモは ceil100(3P) オール(例: 子30符4飜ツモは 3900オール)
- 【確定】ロンの支払いは3方式とも同額(放銃者が打点全額)。ロン打点折半の「ロンの打点」は和了者自身(親・子)のロン打点とする(Issue #13)

### 3.2 本場・供託

| 項目 | 内容 | 設定 |
| --- | --- | --- |
| 本場 | 【確定】1本場あたり場に**200点**(ツモは100オール)。0〜10000点の200点単位(Issue #29) | 変更可 |
| 供託 | 【確定】1本につき**1000点**。0〜10000点の100点単位(Issue #29) | 変更可 |

- 【確定】ロン時は、放銃一家包の原則により、放銃者が設定された1本場あたりの点数(所定値200点)を全額払う。ツモ時は、ツモられた2人が折半して払う(所定値では100オール)
- 【確定】役満の責任払い(包)は扱わない
- 【確定】本場・供託の加算は、和了者の受け取りに加える。供託は和了者が本数×1本あたりの点数を受け取る(Issue #11)
- 【確定】ツモで折半した本場の額が100点単位にならない本場設定は認めず、計算コアは例外を投げる(所定値200点では生じない。Issue #11 の暫定をIssue #13 で確定)
- 【確定】本場数・供託本数は0以上の整数とし、それ以外は例外を投げる(Issue #11)

### 3.3 満貫以上

| 項目 | 内容 | 設定 |
| --- | --- | --- |
| 数え役満 | 【確定】**あり**(13飜以上) | 変更可 |
| 切り上げ満貫 | 【確定】**なし** | 変更可 |
| 役満の複合 | 【確定】**認める** | 変更可 |
| ダブル役満 | 【確定】国士無双十三面待ち・四暗刻単騎・純正九蓮宝燈・大四喜。それぞれ**ダブル役満とする**／役満とする | 変更可 |

- 【確定】役満の複合とダブル役満は、個別に切り替える(Issue #29。準拠先の「他倍役満」は、プリセットでまとめて設定する項目にあたる)

- 【確定】数え役満の飜数には、抜きドラ・赤ドラを含むすべてのドラを含める

## 4. 役

### 4.1 三麻での成立

- 【確定】萬子では順子を作れない。したがって三色同順は成立しない。萬子の一気通貫も成立しない
- 【確定】喰い断は**あり**(変更可)
- 【確定】一発は**あり**(変更可)。なしのときは、立直・オープン立直とも一発を役として数えない(Issue #29)
- 【確定】連風牌の雀頭は**4符**／2符(変更可。Issue #29)

#### 4.1.1 ダブル立直系と槍槓・海底・河底(Issue #26)

- 【確定】ダブル立直・オープンダブル立直で一発がないときは、槍槓・海底撈月・河底撈魚が複合する。根拠は役の定義からの帰結とする(ダブル立直は第1打までの条件、槍槓は他家の加槓へのロンであり、定義上排除し合う条件がない)。準拠先の実機では確認しておらず、確定根拠は役の定義からの帰結とユーザー判断である(§6 の電脳麻将との照合とは性質が異なる)。理論上は複合し得るが、狙って起こすことはほぼ不可能な組み合わせである
- 【確定】ダブル立直・オープンダブル立直で一発があるときは、槍槓・海底撈月・河底撈魚を付けない。加槓に要するポンや海底までの巡目の経過で一発が消えるため、通常は起こり得ない組み合わせとして扱う(国士無双の暗槓への槍槓は役満のため対象外)

### 4.2 ローカル役

【確定】採用するローカル役は下表のとおり。▲は門前役、△は喰い下がりあり。

| 飜数 | 役名 |
| --- | --- |
| 1 | 燕返し・槓振り・推不倒・十二落抬 |
| 2 | 五門斉・三連刻 |
| 3 | 一色三順△ |
| 役満 | 人和・四連刻・一色四順・紅孔雀・紅一点・黒一色・大車輪▲・大竹林▲・石の上にも三年▲・十三不搭▲・八連荘(実装しない)・金門橋▲・東北新幹線▲ |
| ダブル役満 | 純正緑一色・大七星▲ |

- 【確定】オープンリーチを採用できる。所定値は**なし**(変更可)
- 【確定】オープンリーチは2飜、オープンダブルリーチは3飜(立直・ダブル立直の上位として置き換える)
- 【確定】オープンリーチへの故意の放銃(役満払い等の特例)は扱わない
- 【確定】ローカル役は一括でオン・オフする(個別の切り替えはしない)。所定値は**オフ**(変更可)
- 【確定】八連荘は実装しない(一局の計算では判定できないため)。大数隣は2〜8萬を使う役で三麻では成立しないため、採用しない(Issue #14)
- 【確定】一色三順の順子はチーで作れないが、ほかの面子を副露した手(例: 11122233s西西 ロン3s、中ポン)は喰い下がりで2飜とする。三暗刻+三連刻としても読める形では、打点の高い読み方を採る(Issue #14)
- 【確定】天和は和了牌が特定されないため、国士無双は13面待ち、九蓮宝燈は純正九蓮宝燈、四暗刻は四暗刻単騎として扱う(Issue #14)

#### 4.2.1 成立条件(Issue #14)

【確定】Wikipedia「麻雀のローカル役」を下敷きに、オーナーが監修して定めた。推不倒・石の上にも三年・純正緑一色は同記事に記載がなく、オーナーの監修のみによる。

| 役 | 成立条件 |
| --- | --- |
| 燕返し | 他家の立直宣言牌でロンする。追っかけ立直でなくても、ダブル立直の宣言牌でも成立する |
| 槓振り | 他家の槓または北抜きの直後の打牌でロンする。北抜きの牌そのものへのロンには付かない |
| 推不倒 | 1234589p・245689s・白だけで和了する |
| 十二落抬 | 4副露(暗槓を含まない)の裸単騎で和了する。ツモでも成立する |
| 五門斉 | 萬子・筒子・索子・風牌・三元牌をすべて含む。雀頭の制限はなく、副露してもよい |
| 三連刻 | 同色で数字の連続する3刻子(槓子を含む) |
| 一色三順 | 同色同数の順子3組。一盃口とは複合しない |
| 人和 | 子が第一ツモ前にロンする。それまでに鳴きがないこと |
| 四連刻 | 同色で数字の連続する4刻子(槓子を含む) |
| 一色四順 | 同色同数の順子4組 |
| 紅孔雀 | 1579s(0s を含む)と中だけで和了する |
| 紅一点 | 23468s と中だけで和了する。中を含むこと |
| 黒一色 | 248p と東南西北だけで和了する。248p を必ず含む必要はない |
| 大車輪・大竹林 | 2〜8p(大竹林は2〜8s)を2枚ずつ |
| 石の上にも三年 | ダブル立直で、海底または河底で和了する |
| 十三不搭 | 第一ツモ時(鳴きなし)に、面子・搭子がなく、対子が1つだけの形 |
| 金門橋 | 同色の123・345・567・789と雀頭。雀頭は何でもよい |
| 東北新幹線 | 東と北の一方が刻子、他方が雀頭で、残り3面子が一気通貫。抜き北は数えない |
| 純正緑一色 | 發を使わない緑一色。緑一色の上位役で、複合しない |
| 大七星 | 字牌7種の七対子。字一色の上位役で、複合しない |

#### 4.2.2 状況の入力(Issue #14)

- 【確定】燕返し・槓振りは、計算コアの入力に項目を追加して与える。画面は UI の Issue で扱う
- 【確定】人和は専用の入力を設けず、天和・地和の入力を子のロンで用いたときに成立させる。親のロンでは何も付かない
- 【確定】十三不搭は天和・地和と複合しない。国士無双の形も満たす手は国士無双(と天和・地和)とし、十三不搭は付けない
- 【確定】石の上にも三年は、ダブル立直と海底・河底の入力から判定し、専用の入力は設けない
- 【確定】十三不搭は、天和・地和の入力がオンで手牌が十三不搭の形のとき、和了として計算する。専用の入力は設けない
- 【確定】オープンリーチは、立直の入力(なし・立直・ダブル立直)の選択肢にオープン立直・オープンダブル立直を加えて与える

## 5. 管理しないもの

【確定】点数に関係しない次の事項は、計算機では管理しない。

- 槓ドラをめくるタイミング
- 抜き北による一発等の消滅、抜きの順序

## 6. 点数の確定根拠

- 【確定】テストケースは、オーナーが自作した和了形をもとに作成する(Issue #9 で牌譜からの抜粋をやめ、自作に切り替えた)
- 【確定】役・飜・符・基本点の期待値は、手計算(Wikipedia に基づく)と電脳麻将(kobalab)の和了点計算の両方で一致を確かめたものに限る。テストの対象である livewing/mahjong-calc は検算に使わない(Issue #9)
- 【確定】基本点は、Wikipedia「麻雀の得点計算」の計算式で算出する(Issue #9)
- 【確定】ローカル役とオープンリーチは電脳麻将が対応しないため、役の成否と飜数は§4.2.1の定義、点数は手計算で期待値を定める(Issue #14)
- 【確定】ダブル立直系と槍槓の複合(§4.1.1)は準拠先の実機確認がないため、役の成否は§4.1.1の定義、点数は手計算で期待値を定める。これは役の定義からの帰結とユーザー判断による確定であり、電脳麻将との照合を経たものではない(Issue #26)

## 7. 卓情報

- 【確定】自風は東・南・西のみ。場風は東・南・西のいずれか(北場はない)(Issue #11)
- 【確定】親は自風が東の者。親か子かは自風から決まり、独立した入力ではない(Issue #11)
