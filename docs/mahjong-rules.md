# 麻雀ルール仕様

更新日: 2026-10-20(Issue #9 のヒアリングで§6を確定)

本アプリが計算の前提とする三人麻雀のルール。オーナーの提示(2026-10-20)を正本とし、確度を【確定】【未確定】のタグで区別する。扱い方は[業務標準07](rules/07-mahjong-rule-protocol.md)による。

- 【確定】雀魂・麻雀一番街に準拠する。この文書に書かれた内容は、準拠先より優先する
- 【確定】雀魂と麻雀一番街のどちらのルールにも対応する。どちらかを優先するのではなく、プリセット「雀魂段位戦」「一番街段位戦」を用意し、各項目は利用者が好みで設定できるようにする
- 【未確定】各プリセットの具体的な設定値(Epic B のヒアリングで、準拠先の公式ルールを出典に確定させる)

「設定」欄が「変更可」の項目は、ルール設定で切り替えられるようにする。所定値は**太字**で示す。

## 1. 牌とドラ

| 項目 | 内容 | 設定 |
| --- | --- | --- |
| 牌構成 | 【確定】萬子は 1m・9m のみ(2m〜8m なし)。筒子・索子・字牌は全種。各4枚、計108枚 | — |
| 赤ドラ | 【確定】`5p`・`5s` のみ。赤なし／**2枚**(5p・5s 各1枚)／4枚(5p・5s 各2枚)。全赤は採用しない | 変更可 |
| ドラ表示牌 | 【確定】萬子は表示牌 `1m` でドラ `9m`、表示牌 `9m` でドラ `1m`。筒子・索子・字牌は通常どおり | — |
| 槓ドラ・槓裏 | 【確定】あり。めくるタイミングは点数に関係しないため管理しない | — |
| 裏ドラ | 【確定】あり(立直時) | — |

## 2. 北

| 項目 | 内容 | 設定 |
| --- | --- | --- |
| 北の扱い | 【確定】**抜きドラ**／共通役牌。両者は排他 | 変更可 |
| 抜きドラ | 【確定】抜いた北1枚につき1飜(ドラ扱い)。抜いた北は手牌の枚数に数えない | — |
| 抜きドラ(手牌での使用) | 【確定】抜かずに手牌で使う北は客風牌として扱う(役牌にならない) | — |
| 抜きドラ(付随事項) | 【確定】抜きによる一発等の消滅、抜き後の嶺上開花、嶺上放銃(槓振り)の対象になる。ただし点数に関係しないため、抜きの順序や消滅は管理しない | — |
| 抜き北への槍槓 | 【確定】抜き北でロンできるが、槍槓の役は付かない | — |
| 共通役牌 | 【確定】北の刻子・槓子で1飜役「役牌：北」。雀頭は2符で、平和にならない(挙動は三元牌と同じ) | — |

## 3. 点数と支払い

### 3.1 ツモ損

| 方式 | 内容 | 設定 |
| --- | --- | --- |
| **ツモ損あり** | 【確定】通常どおり計算し、北家の負担分は誰も払わない | 変更可 |
| 北家分折半 | 【確定】北家の負担額を、ツモられた2人で折半して上乗せする | 変更可 |
| ロン打点折半 | 【確定】ロンの打点を、親子に関わらず2人で折半して支払う | 変更可 |

満貫ツモの例(【確定】):

| 方式 | 親のツモ | 子のツモ |
| --- | --- | --- |
| ツモ損あり | 4000オール → 8000点 | 2000・4000 → 6000点 |
| 北家分折半 | 6000オール → 12000点 | 3000・5000 → 8000点 |
| ロン打点折半 | 6000オール → 12000点 | 4000オール → 8000点 |

- 【未確定】北家分折半・ロン打点折半での端数処理(満貫未満で、折半した額が100点単位にならない場合)。準拠先の挙動が確認できるまで保留する

### 3.2 本場・供託

| 項目 | 内容 | 設定 |
| --- | --- | --- |
| 本場 | 【確定】1本場あたり場に**200点**(ツモは100オール) | 変更可 |
| 供託 | 【確定】1本につき**1000点** | 変更可 |

- 【確定】ロン時は、放銃一家包の原則により、放銃者が設定された1本場あたりの点数(所定値200点)を全額払う。ツモ時は、ツモられた2人が折半して払う(所定値では100オール)
- 【確定】役満の責任払い(包)は扱わない

### 3.3 満貫以上

| 項目 | 内容 | 設定 |
| --- | --- | --- |
| 数え役満 | 【確定】**あり**(13飜以上) | 変更可 |
| 切り上げ満貫 | 【確定】**なし** | 変更可 |
| 役満の複合 | 【確定】認める | — |
| ダブル役満 | 【確定】国士無双十三面待ち・四暗刻単騎・純正九蓮宝燈・大四喜 | — |

- 【確定】数え役満の飜数には、抜きドラ・赤ドラを含むすべてのドラを含める

## 4. 役

### 4.1 三麻での成立

- 【確定】萬子では順子を作れない。したがって三色同順は成立しない。萬子の一気通貫も成立しない
- 【確定】喰い断は**あり**(変更可)

### 4.2 ローカル役

【確定】採用するローカル役は下表のとおり。▲は門前役、△は喰い下がりあり。

| 飜数 | 役名 |
| --- | --- |
| 1 | 燕返し・槓振り・推不倒・十二落抬 |
| 2 | 五門斉・三連刻 |
| 3 | 一色三順△ |
| 役満 | 人和・四連刻・一色四順・紅孔雀・紅一点・黒一色・大車輪▲・大数隣▲・大竹林▲・石の上にも三年▲・十三不搭▲・八連荘(実装しない)・金門橋▲・東北新幹線▲ |
| ダブル役満 | 純正緑一色・大七星▲ |

- 【確定】オープンリーチを採用できる。所定値は**なし**(変更可)
- 【確定】オープンリーチは2飜、オープンダブルリーチは3飜(立直・ダブル立直の上位として置き換える)
- 【確定】オープンリーチへの故意の放銃(役満払い等の特例)は扱わない
- 【確定】ローカル役は一括でオン・オフする(個別の切り替えはしない)。所定値は**オフ**(変更可)
- 【未確定】各ローカル役の成立条件の正確な定義と出典(実装する Issue のヒアリングで、準拠先の公式ルールから確定させる)
- 【確定】八連荘は実装しない(一局の計算では判定できないため)。それ以外の、牌姿だけでは判定できない役(燕返し・槓振り・人和・石の上にも三年)は実装する
- 【未確定】それらの役の状況の入力方法(実装する Issue でオーナーが指示する)

## 5. 管理しないもの

【確定】点数に関係しない次の事項は、計算機では管理しない。

- 槓ドラをめくるタイミング
- 抜き北による一発等の消滅、抜きの順序

## 6. 点数の確定根拠

- 【確定】原則として、牌譜をもとにテストケースを作成する
- 【確定】役・飜・符の期待値は、雀魂・麻雀一番街の和了画面をオーナーがまとめたスプレッドシートを出典とする。和了画面・手計算・電脳麻将(kobalab)の和了点計算のうち2つ以上で検算したものに限る。テストの対象である livewing/mahjong-calc は検算に使わない(Issue #9)
- 【確定】基本点は、Wikipedia「麻雀の得点計算」の計算式で算出する(Issue #9)
