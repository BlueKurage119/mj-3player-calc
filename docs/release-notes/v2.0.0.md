# 三麻点数計算機 v2.0.0

三人麻雀に特化したスマホ向けの点数計算機（PWA）です。
https://bluekurage119.github.io/mj-3player-calc/

## 主な変更点（v1.1.0 からの差分）

### 何切るの確率・期待値シミュレーションを追加
- 聴牌・向聴・何切るの結果から「計算」ボタンで専用画面を開き、巡目ごとの **和了率・聴牌率・期待値** をグラフと打牌候補一覧で確認できるようになりました。オフラインでも動作します。
- 計算方式は「概算」と「手替わりを詳しく」の 2 段階から選べます。1〜18 巡目の表示スライダー、和了率・聴牌率・期待値での並び替え、計算途中の取り消しにも対応しています。

### 見た目・操作性・更新体験の改善
- **ヘッダーのスクロール連動デザイン**: スクロール量に応じてヘッダー背景色がなめらかに変化するようになり、固定カードやダイアログとの重なりを見やすく整えました。
- **iOS でのステータスバー表示改善**: iOS 環境でステータスバー領域が透ける現象を抑える調整を行いました。
- **計算中インジケーターの改善**: 計算中の表示を大きな円形プログレスインジケーターへ変更しました。
- **アプリ更新通知の導入**: 新しいバージョンが配信された際に画面下部へ更新通知を表示し、アプリを開いたままでも安全に更新できるようになりました。
- **その他**: ヘルプ画面の内容更新・表記統一、ライセンス表示の拡充、タップ領域の調整を行いました。

## v1.1.0 からのアップデートについて
- v1.1.0 には更新通知機能がないため、**v1.1.0 から v2.0.0 への初回更新時のみ、アプリ（またはブラウザタブ）を一度開いてから完全に終了して起動し直す**と v2.0.0 に切り替わります。v2.0.0 以降はアプリ内の更新通知から更新できます。

## 既知の制約
- **確率・期待値シミュレーションの前提と近似**:
  - 他家の和了・鳴き・流局を考慮しない一人麻雀モデルで、ツモ和了のみを数えます。
  - 18 巡分のツモを見込んだ期待値最大方針による累積近似です。4 向聴以上の手牌は計算対象外です。
  - 山と裏ドラは確率で近似します。一発・ダブル立直・天和・地和・海底は含めず、立直棒・本場（積み棒）・供託も計算に含めません。
- **テーマ設定とステータスバー・起動背景**: アプリ内で手動テーマを OS と逆（例: OS ダーク＋アプリライト）に設定している場合、ステータスバーの色とヘッダー色に差が生じます。また、PWA の起動時背景は暗色固定です。
- **視覚効果を減らす設定**: OS で「視覚効果を減らす」が有効な場合、計算中の円形インジケーターは静止表示になります。
- **Firefox の対応バージョン**: 確率・期待値シミュレーションは Firefox 114 以降で利用できます（Firefox 89〜113 では非対応）。
