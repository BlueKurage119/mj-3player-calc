# 三麻点数計算機 v1.1.0

三人麻雀に特化したスマホ向けの点数計算機です。
https://bluekurage119.github.io/mj-3player-calc/

## 主な変更点（v1.0.0 からの差分）

### 点数計算表の拡張（#105・#106）
- **本場（積み棒）の反映（#105）**: 積み棒ステッパーを追加し、1 本場以上（かつ本場点数設定が 0 より大きい場合）は「`1,000 は 1,200`」「`300・500 は 400・600`」のように申告額と本場込み額を併記します。画面を開くたびに主画面の積み棒数を初期値として読み込みます（画面内の変更は主画面へ書き戻しません）。
- **点差表示・供託の反映（#106）**: ヘッダー右端に「得点 / 点差」の切替を追加しました。点差モードでは供託ステッパーが表示され、三麻 2 人払い・ツモ損 3 方式に対応した相手との点差縮まり幅（直撃・親ツモ・子ツモの対子/対親）を負数表記で確認できます。
- **点数計算表 UI の改善**: 操作行の上部固定、ツモ損なし計算方式ピルの強調、満貫〜役満の名称 2 段表示、MD3 トークン（`quinary`・`senary` 追加）による満貫以上 60° 刻みの色階調整理、切り上げ満貫なし時の対象セル（30符4飜・60符3飜）の薄塗り表示を追加しました。

### 十三不搭のチャンス・成立メッセージ（#85）
- ローカル役オンかつ天和・地和オフ時において、十三不搭の成立・チャンス状態を向聴の待ちカード様式（M種 N枚・牌と残り枚数）で案内するようにしました。

### その他の修正・改善（v1.0.1 プレリリース分を含む）
- 設定画面の二重余白・gap を修正しました（#130）。
- 和了解釈の同点比較（生の符の比較）を検証する単体テストを追加しました（#92・#129）。
- プレビュー環境および開発ドキュメント類を整備しました。
