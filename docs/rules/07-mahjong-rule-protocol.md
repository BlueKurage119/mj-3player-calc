# 麻雀ルール・点数計算業務標準

対象: 役・符・点数・支払い・有効牌・ルール設定に関わる設計・製造・検収。ルールの内容そのものは[麻雀ルール仕様](../mahjong-rules.md)を正本とする。

## 確定事実の扱い(必須)

1. ルールの解釈は、[麻雀ルール仕様](../mahjong-rules.md)の【確定】の記述だけを「確定」事実として扱う。
2. 仕様に書かれていない事項や【未確定】の事項を、一般的な四人麻雀のルールや自分の知識で補わない。設計担当は【設計案】として書き、要ヒアリング事項に回す。製造担当は実装を止めて報告する。
3. ヒアリングで確定した事項は、統括担当が仕様の改訂として反映する(設計書だけに書いて終わらせない)。
4. 「管理しないもの」(仕様の§5)を実装しない。

## 所定値(必須)

- ルール設定の所定値(初期値)は仕様の太字のとおりとし、設計・製造の都合で変更しない。
- 仕様で「変更可」の項目は、すべての選択肢を設定で選べるようにする。

## 三麻の不変条件(必須)

設計・実装・検収のいずれの段階でも、次が守られているかを確認する。

- 2m〜8m は、入力・有効牌・受け入れ・待ち・残り枚数のどこにも現れない
- チーは存在しない。自風は東・南・西のみ
- 残り枚数は108枚の構成を前提にし、抜き北・手牌・副露・ドラ表示牌を差し引く

## 点数の期待値(必須)

- テストの期待値(役・飜・符・点数・支払い)は、牌譜・仕様の点数例・準拠先の点数表など、実装とは独立した出典から取る。テストに出典をコメントで残す。
- 仕様の点数例(満貫ツモの各方式など)は、そのままテストケースにする。
- ルール設定を追加・変更したときは、その項目のすべての選択肢について、結果が変わる代表的な牌姿で検証する。
