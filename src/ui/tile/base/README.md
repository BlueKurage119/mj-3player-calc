# 牌の下地・裏素材 (base)

このディレクトリに含まれる SVG ファイルは、livewing/mahjong-calc から取り込んだ牌の表の下地および裏の画像です。
出典の値を保つため、手動で値の変更を行わないでください。

## 備考

既存の命名およびテスト規約との整合性のため、元ファイル名 (`bg.svg` / `back.svg`) から `Front.svg` / `Back.svg` へ改名して配置しています。内容は元ファイルそのままであり、SVGO による再加工は行っていません。
